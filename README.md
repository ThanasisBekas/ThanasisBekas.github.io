# thanasisbekas.github.io

Source of [thanasisbekas.github.io](https://thanasisbekas.github.io): a portfolio as a retro island adventure,
with the plain CV one click away.

TypeScript and Canvas 2D, no game engine. All art is drawn in code and all sound is synthesised.
Designed and built with AI coding agents.

```bash
npm ci
npm run dev
npm run build
```

`index.html` is the only copy of the content: it is the plain CV, and each place on the island shows one section of it.
A push to `main` deploys to GitHub Pages.

The logo font is Pixelify Sans, under the [SIL Open Font License](public/licenses/pixelify-sans.txt).
